===== ENGLISH =====
⚡ Unofficial Manifest V3 port of AutoControl (keyboard shortcuts + mouse gestures)

The original AutoControl extension was removed from the Chrome Web Store. This is a community port so those shortcuts and gestures still work on current Chrome.

⚠️ Not the original product. Not listed as a packaged store item in this repo — load the unpacked mv3-build folder in developer mode.

✨ What still works
• Keyboard shortcuts and mouse gestures through the original Windows native engine
• Open URL — including chrome:// pages (history, bookmarks, extensions)
• Tab actions: switch, pin, mute, reopen closed tab
• Run Script / ACtl on normal web pages (enable “Allow user scripts”)
• Settings import / export (.acs)

🔧 Setup
1. Load unpacked → select the mv3-build folder (keep that folder; do not flatten the repo)
2. Click Install when the native-component pane appears
3. Chrome → Details → turn on “Allow user scripts”
4. Restore settings from a .acs file uses Replace (not Add). Sample file in the repo: My-AutoControl-Settings.acs

📌 Why this port
Chrome Manifest V3 killed the always-on background page. The original team stopped. This build runs the same obfuscated logic in a service worker plus shims. Some hover-region conditions are broken in Chrome 148+ (native hit-test, MV2 and MV3 alike).

🔒 Privacy
Settings stay on your PC. Usage telemetry is off unless you enable it in Advanced Options. Policy: PRIVACY.md in the GitHub repo.

===== 简体中文 =====
⚡ AutoControl 非官方 Manifest V3 移植（快捷键 + 鼠标手势）

原版 AutoControl 已从 Chrome 网上应用店下架。本仓库把快捷键和鼠标手势接到现行 Chrome 上继续用。

⚠️ 不是原厂产品。本仓库不以商店打包安装为准 — 请在开发者模式下加载解压后的 mv3-build 文件夹。

✨ 还能做的事
• 经原版 Windows 原生组件处理快捷键与鼠标手势
• 打开网址，包括 chrome:// 页面（历史、书签、扩展程序）
• 标签操作：切换、固定、静音、重新打开已关闭标签
• 在普通网页上运行脚本 / ACtl（需打开「允许用户脚本」）
• 导入 / 导出设置（.acs）

🔧 安装
1. 加载已解压的扩展程序 → 选中 mv3-build 文件夹（请保留该目录，不要把仓库摊平）
2. 出现原生组件安装页时点 Install
3. 扩展详情里打开「允许用户脚本」
4. 从 .acs「从文件还原」是替换而不是追加。仓库示例：My-AutoControl-Settings.acs

📌 为什么要移植
Manifest V3 拿掉了常驻后台页，原团队停更。本构建把同一套混淆逻辑跑在 Service Worker 上。Chrome 148+ 的悬停区域条件失效（原生无障碍命中测试问题，MV2/MV3 一样）。

🔒 隐私
设置只存在本机。匿名用量默认关闭，可在高级选项里打开。政策见仓库 PRIVACY.md。

===== 日本語 =====
⚡ AutoControl 非公式 Manifest V3 移植（キーボードショートカット + マウスジェスチャ）

元の AutoControl は Chrome ウェブストアから削除されました。現行 Chrome でもショートカットとジェスチャを使うためのコミュニティ移植です。

⚠️ 公式製品ではありません。このリポジトリはストア用パッケージインストールを前提にしていません。デベロッパーモードで mv3-build フォルダを読み込んでください。

✨ できること
• 元の Windows ネイティブエンジンによるショートカットとマウスジェスチャ
• URL を開く（chrome:// の履歴・ブックマーク・拡張機能ページを含む）
• タブ操作：切り替え、ピン留め、ミュート、閉じたタブを開き直す
• 通常のウェブページで Run Script / ACtl（「ユーザースクリプトを許可」が必要）
• 設定のインポート / エクスポート（.acs）

🔧 セットアップ
1. パッケージ化されていない拡張機能を読み込む → mv3-build フォルダを選ぶ（フォルダは残す）
2. ネイティブコンポーネントの画面で Install
3. 詳細で「ユーザースクリプトを許可」をオン
4. .acs からの復元は追加ではなく置き換え。サンプル：My-AutoControl-Settings.acs

📌 移植の理由
Manifest V3 で常駐バックグラウンドページがなくなり、元チームは開発を止めました。同じ難読化ロジックをサービスワーカーで動かしています。Chrome 148 以降のホバー領域条件はネイティブ側のヒットテスト不具合で効きません（MV2 も同じ）。

🔒 プライバシー
設定はパソコン内に保存。匿名テレメトリは既定オフ。方針はリポジトリの PRIVACY.md。
