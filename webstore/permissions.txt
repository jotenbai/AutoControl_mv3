===== Chrome Web Store permission justifications (paste per field) =====
Remote code: select 「不，我并未使用远程代码」.
The extension JS, WASM and native binaries all ship in the ZIP. User Run Script / ACtl source is stored in chrome.storage on the device. Fetching a page to save it, or importing a settings JSON the user chose, is not executing remotely hosted extension code.
If the form is already 「是」, change it to 「否」 before submit.

----- nativeMessaging -----
Used only to talk to the local Windows native host “hrich.autocontrol” (AutoControlZero.exe + engine in %LocalAppData%\AutoControl). Global keyboard shortcuts, mouse gestures, SendInput and local file IO cannot run in a service worker; they run in that host. No remote server. The host is installed by the user from binaries bundled in the extension.

----- storage -----
Stores the user’s triggers, actions, scripts, gesture options and UI flags in chrome.storage.local so they survive browser restarts. No account. Nothing is synced to our servers.

----- unlimitedStorage -----
A full settings backup includes many actions, icons (data URLs) and user scripts. This can exceed Chrome’s 10 MB storage.local quota. unlimitedStorage keeps large local configs from being silently truncated.

----- contextMenus -----
Adds an “Emergency repair” item (and optional switch-state items) on the toolbar-icon context menu so the user can restart the native connection if hotkeys stop. Not used for page context spam or ads.

----- system.display -----
Reads monitor bounds and DPI so window/popup actions (custom menus, toasts) are placed on the correct display. The native host also receives this layout. Display geometry only, not screenshot capture.

----- idle -----
chrome.idle detects when the browser is idle or locked so we can pause native keepalive pings and run user-defined “on idle / on active” triggers. Query interval is the Chrome idle API, not keystroke logging.

----- scripting -----
Injects the in-page script bridge and optional site “Import/View settings” helper on pages the user is using. Needed because Manifest V3 has no persistent background page. Not used to inject ads or unrelated third-party scripts.

----- alarms -----
chrome.alarms keeps the Manifest V3 service worker alive and sends a periodic native keepalive so global hotkeys still work after Chrome hibernates the worker. No scheduling of remote jobs.

----- favicon -----
The chrome://favicon access is used only to show site icons in the custom tab-switcher menu. Favicons are cached locally for that UI. Not used to fetch arbitrary URLs.

----- tabs -----
Query / create / update / reload tabs so actions can open a URL (including chrome://history, bookmarks, extensions), switch, pin, mute, or reopen tabs. Tab URL/title are read to evaluate user-defined conditions. Not used for browsing-history export or analytics by default.

----- offscreen -----
An offscreen document hosts (1) the sandboxed iframe that runs background “Run Script” actions and (2) Web Audio / speech for “Play audio”. Service workers have no DOM or AudioContext. No hidden extra windows for tracking.

----- userScripts -----
Official Manifest V3 API to run user-authored “Run Script” / ACtl code in the USER_SCRIPT world (works on strict-CSP sites). Code comes from the user’s saved settings, not from our servers. The user must also enable “Allow user scripts” on chrome://extensions.

----- declarativeNetRequestWithHostAccess -----
Only to set a Referer header on the extension’s own Save-URL fetch (MV2 used blocking webRequest, which MV3 removed). Session rules are added for that download and removed afterwards. Not used to block or redirect the user’s normal browsing.

----- bookmarks -----
Optional. Requested only if the user creates or imports an action that reads/writes a bookmark folder. Not requested at install for users who never use those actions.

----- sessions -----
Optional. Used only for “Reopen closed tab” (chrome.sessions.restore). Requested when the user enables that action. Recently-closed session data stays in Chrome; we do not upload it.

----- notifications -----
Optional. Shows completion/error toasts (for example Save URL finished, or a native-hook conflict). “Don’t show again” is respected. Not used for promotional notifications.

----- downloads -----
Optional. Used when a Save-URL action uses chrome.downloads, and (rarely) to save a small local helper script that adds this extension’s ID to the native-host whitelist. Files go to the user’s Downloads folder. Not used to download unrelated software in the background.

----- Host permissions (<all_urls>) -----
Triggers, mouse gestures and optional Run Script must run on whichever page the user is looking at. URL conditions and “Open URL” destinations are defined by the user and include chrome:// and arbitrary https sites, so a fixed host list is not possible. We do not scrape the web or inject ads. Host access is used only to (1) match the active tab against the user’s conditions, (2) inject the script bridge when the user runs a script, (3) open/save the URL the user configured.

===== 中文粘贴版（控制台是中文时用下面各段） =====

----- nativeMessaging -----
仅用于连接本机 Windows 原生组件 hrich.autocontrol（%LocalAppData%\AutoControl 下的 AutoControlZero.exe 与引擎）。全局快捷键、鼠标手势、模拟按键和本地文件读写无法在 Service Worker 里完成，必须走该组件。不连接我们的服务器。安装包由用户从扩展内嵌文件安装。

----- storage -----
把用户的触发器、动作、脚本、手势选项存在 chrome.storage.local，以便重启后仍在。无账号。默认不同步到我们的服务器。

----- unlimitedStorage -----
完整配置含大量动作、图标（data URL）和用户脚本，可能超过 storage.local 默认 10MB。此权限避免本地配置被截断。

----- contextMenus -----
在工具栏图标右键菜单中提供「Emergency repair」（以及可选的开关项），用于原生组件卡住时修复。不用于网页右键广告。

----- system.display -----
读取显示器工作区和 DPI，以便弹窗/自定义菜单出现在正确屏幕上，并同步给原生组件。只用几何信息，不截屏。

----- idle -----
用 chrome.idle 判断浏览器空闲/锁定，以便暂停原生保活，并执行用户配置的「空闲/恢复」类触发器。不是记录键盘。

----- scripting -----
向用户正在使用的页面注入脚本桥，以及设置站的导入/查看按钮。Manifest V3 没有常驻后台页。不注入广告或无关第三方脚本。

----- alarms -----
用 chrome.alarms 维持 Service Worker，并定期给原生组件保活，避免 Chrome 休眠 worker 后快捷键失效。不用于远程定时任务。

----- favicon -----
仅用于自定义标签切换菜单显示网站图标（chrome://favicon）。图标缓存在本地。不用于随便拉取网址。

----- tabs -----
查询/创建/更新/刷新标签，以实现打开网址（含 chrome:// 历史、书签、扩展程序页）、切换、固定、静音、重开已关闭标签。读取 URL/标题是为了匹配用户写的条件。默认不导出历史、不做分析。

----- offscreen -----
Offscreen 文档用于：（1）后台 Run Script 的沙箱 iframe；（2）播放音频（Worker 没有 AudioContext）。不是隐藏跟踪窗口。

----- userScripts -----
用官方 userScripts API 执行用户自己写的 Run Script / ACtl（可在严格 CSP 页面运行）。代码来自用户保存在本地的设置，不是我们的服务器。用户还需在 chrome://extensions 打开「允许用户脚本」。

----- declarativeNetRequestWithHostAccess -----
仅在「保存网址」时为扩展自己的 fetch 临时设置 Referer（MV2 的 blocking webRequest 在 MV3 已删除）。用完即删 session 规则。不拦截用户日常浏览。

----- bookmarks -----
可选权限。仅当用户创建或导入了书签文件夹相关动作时才申请。不用这些动作的用户不会在安装时被要此权限。

----- sessions -----
可选权限。仅用于「重新打开已关闭的标签」（chrome.sessions.restore）。关闭标签记录留在 Chrome 本地，不上传。

----- notifications -----
可选权限。用于保存完成/失败、以及原生钩子冲突等提示。支持不再显示。不做推广通知。

----- downloads -----
可选权限。用于「保存网址」走 chrome.downloads，以及偶尔保存一个把本扩展 ID 写入原生白名单的本地小脚本。文件进入用户的下载文件夹。不在后台下载无关软件。

----- 主机权限 -----
快捷键、鼠标手势和可选脚本必须作用在用户当前查看的页面上。网址条件和「打开网址」的目标由用户自己配置，包含 chrome:// 和任意 https，无法写成固定域名列表。不用于抓取网页或插入广告。主机权限只用于：（1）用用户的条件匹配当前标签；（2）用户运行脚本时注入脚本桥；（3）打开或保存用户配置的网址。
