===== ENGLISH =====
⛔ STORE BUILD DOES NOT WORK — do not install from the Chrome Web Store.

Native keyboard/mouse hooks cannot safely share a Chrome profile with a second
extension ID. The Web Store listing (if still visible) is abandoned.

✅ Install from GitHub instead (Load unpacked → the extension/ folder):
https://github.com/jotenbai/AutoControl_mv3

Keep that folder on disk; Chrome must keep reading it. Full steps are in the

⚡ AutoControl_mv3 — unofficial Manifest V3 port (keyboard shortcuts + mouse gestures)

The original AutoControl listing was removed from the Chrome Web Store. This is a community port.

⚠️ Not the original product. Not affiliated with the original authors. Settings UI stays in English.

✨ What still works (when installed from GitHub as above)
• Keyboard shortcuts and mouse gestures through the original Windows native engine
• Those shortcuts still work on Chrome’s own chrome:// pages (history, bookmarks, extensions)
• Open URL, including chrome:// pages
• Tab actions: switch, pin, mute, reopen closed tab
• Run Script / ACtl on normal web pages (enable “Allow user scripts”)
• Settings import / export (.acs)

🔧 Setup (GitHub only)
1. Clone or download https://github.com/jotenbai/AutoControl_mv3
2. chrome://extensions → Developer mode → Load unpacked → select the extension/ folder
3. Open the extension → Install the native component
4. Details → turn on “Allow user scripts”
5. Sample shortcuts: https://github.com/jotenbai/AutoControl_mv3#built-in-shortcuts-first-install

🔒 Privacy
Settings stay on your PC. Policy: https://github.com/jotenbai/AutoControl_mv3/blob/master/webstore/privacy.md

⚠️ 不是原厂产品，与原作者无关。设置界面仍为英文。

✨ 从 GitHub 按上面方式安装后可用

⚡ AutoControl_mv3 — 非公式 Manifest V3 移植（キーボードショートカット + マウスジェスチャ）

元の AutoControl は Chrome ウェブストアから削除されました。これはコミュニティによる移植です。

⚠️ 公式製品ではありません。元の作者とは無関係です。設定 UI は英語のままです。

✨ GitHub から上記の方法で入れた場合に使える機能
• 元の Windows ネイティブエンジンによるショートカットとマウスジェスチャ
• Chrome 自身の chrome:// ページでも動作
• URL を開く（chrome:// を含む）
• タブ操作：切り替え、ピン留め、ミュート、閉じたタブを開き直す
• 通常ページで Run Script / ACtl（「ユーザースクリプトを許可」が必要）
• 設定のインポート / エクスポート（.acs）

🔧 セットアップ（GitHub のみ）
1. https://github.com/jotenbai/AutoControl_mv3 をクローンまたはダウンロード
2. chrome://extensions → デベロッパーモード → パッケージ化されていない拡張機能を読み込む → extension/ を選択
3. 拡張機能を開く → ネイティブコンポーネントを Install
4. 詳細で「ユーザースクリプトを許可」をオン
5. サンプル：https://github.com/jotenbai/AutoControl_mv3#built-in-shortcuts-first-install

🔒 プライバシー
設定はパソコン内に保存。方針：https://github.com/jotenbai/AutoControl_mv3/blob/master/webstore/privacy.md
